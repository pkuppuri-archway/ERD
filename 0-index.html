      Reading the explorer

      PK marks the original SQL's informational primary key. J marks a column used at either end of a registered proposed join, not an enforced foreign key. Expand a column to read its source comment.

      Table types are navigation categories derived from name prefixes. Source groups retain the export's G01-G10 codes. Neighborhood shows the selected table and its immediate connections; type, group, and search filters still apply.

      Use arrow keys on the focused canvas to pan, + and - to zoom, and Home to fit. Use arrow keys in the table list to move between tables; Enter selects. Escape clears the focused search. All data is embedded in this file; it makes no network requests.
